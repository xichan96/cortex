- Performs an exact string replacement in a file.
- Use this for targeted changes instead of rewriting the whole file.

Usage notes:
  - Requires `file_path`, `old_string`, and `new_string`.
  - `old_string` must match the file exactly, including indentation.
  - By default `old_string` must be unique in the file: 0 or multiple matches are errors. Set `replace_all` to true to replace every occurrence.
  - The optional `hunks` array applies several replacements atomically in one call.
